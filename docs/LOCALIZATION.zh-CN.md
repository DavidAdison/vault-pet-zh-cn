# 简体中文本地化实现与验收

## 结构

1. `src/kit/i18n.js`：英韩基础字典、翻译接口、语言列表、语言标识解析和地区格式映射。
2. `src/kit/i18n-obsidian.js`：Obsidian 写作场景覆盖层，保留原英韩内容，补充自动语言和错误提示。
3. `src/kit/i18n-zh-CN.js`：独立中文资源，在上述两层之后加载，含 UI、台词和像素动画文字。
4. `scripts/build.js`：将三层资源同时装入 CommonJS 宿主模块和 iframe 初始化函数。
5. `src/plugin/main.js` 与 `host.js`：语言检测、设置选择器、通知、菜单、命令更新和渲染器配置。
6. `src/kit/house.js`、`pet.js`、CSS、`sprite.js`：界面语言、中文格式、字体换行及像素动画中的汉字显示。

`language` 仍是原存档设置字段。新增支持值 `zh-CN` 与 `auto`，没有新增持久化字段、迁移数据结构或修改插件 ID。小屋通信载荷中的顶层 `language` 是解析后的显示语言，保存仍使用原 `settings` 对象。自动模式不会在保存时被解析值覆盖。

已有手动语言选择优先；新安装默认 `auto`。`zh`、`zh-CN`、`zh-SG`、`zh-Hans` 及 `zh-Hans-*` 映射为 `zh-CN`，`ko*` 映射为 `ko`，其他标识回退 `en`，不把繁体中文误认为简体中文。

## 边界与术语

- 保留 `src/core/` 的全部原始实现：等级/金币公式、价格、解锁、任务、成就、物品 ID 与奖励不变。
- 保留 `manifest.json`、存档版本和存档读写/恢复机制。
- “经验值（XP）”“金币”“每日任务”“成就”“背包”“衣橱”“饱腹度”“活力”按场景统一。
- 英韩字典原有词条不改写，只增加新选项和错误消息所需键。
- 保留 `{name}`、`{n}` 等变量；中文不使用韩语助词语法。保留 `||` 连续气泡及邻居 `f:` / `c:` 说话者标记。
- 不改用户名称、笔记、文件夹名称或存档中的历史自由文本。
- 分享卡复制失败时显示本地化错误，避免把失败显示成复制成功；保存失败保留系统错误详情并提供本地化前缀。这些属于显示层反馈。
- 动画仅调整文字的翻译与绘制；中文使用系统字体，英韩沿用原位图字母。

## 验收

原版基线：34/34 项测试通过，原构建脚本成功。

汉化版：

- 43/43 项 Node.js 测试通过，包含原版全部测试。
- 覆盖全部原版 2,080 个 UI 键；加入新选项、错误和动画词条后共 2,171 个中文键。
- 共 108 类、247 条中文台词；逐条检查变量与分段数量。
- 检查 UI 占位符、HTML 标记、邻居对话分段与说话者标记一致，避免回退韩语或显示原始键。
- 检查手动选择优先、简体标识解析、自动模式保持、非法设置拒绝。
- 检查语言切换前后除 `settings.language` 外的设置和整个游戏状态不变。
- 加载构建产物，验证宿主与 iframe 均有中文资源。
- 31 项 Chrome 浏览器冒烟检查通过：八个主页面、商店与背包子页、英韩中及自动切换、首次引导、窄侧栏/深色主题、宠物气泡及加载文案，无浏览器脚本异常或整页横向溢出。

浏览器检查使用合成数据。没有在用户的实际 Obsidian 笔记库中覆盖安装，因此真实宿主中的最终安装体验需由下载用户确认。测试不包含所有小游戏完整玩法，也不承诺与所有第三方主题兼容。
